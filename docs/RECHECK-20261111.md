# 2026-11-11 功能复查

补丁版本：`0.1.2`。本次复查在已发布 `0.1.1` 的全后端测试仍然通过的前提下，增加独立边界用例和真实浏览器操作，发现并修复以下问题。

| 问题 | 修复后的行为 |
| --- | --- |
| `/src/*.mbt` 与 `src/*.mbt` 匹配不一致 | 前导斜杠不成为目标相对路径的一部分，原有目录限定语义保留 |
| `literal\*.txt` 被反斜杠误判为带目录的模式 | 反斜杠用于转义，模式仍可以匹配子目录中的字面星号文件名 |
| `{4294967296..4294967297}` 因 Int32 回绕匹配 `0`、`1` | 使用检查溢出的 Int64 端点；最大、最小端点均有回归用例 |
| `[ab*c{1..2}]` 中字面花括号被展开 | 展开扫描跳过合法字符集合 |
| `tab_width = unset` 删除后又从 `indent_size` 派生 | 记录显式取消状态，后续显式赋值会清除该状态 |
| Studio 显示“第 undefined 行”，点击诊断选中空文本 | 页面读取 `start.line`，实际 Chrome 验证第 1、4、7 行的选区与源代码一致 |

单个数字范围最多展开 1,001 项，超出上限或 Int64 端点范围时保留字面量；降序范围为既有兼容扩展。字符通配和字符集合仍按 UTF-16 码元工作，补充平面字符的通配边界见 README，未将本次修复表述为完整规范认证。

## 验证入口

工具链为 `moonc v0.10.20+65efd5b93 (2026-11-05)`，`moon` / `moonrun 0.1.20261104 (940aa18 2026-11-04)`；依赖仍为 `moonbitlang/x@0.5.7`。

```text
moon check --target all --deny-warn
moon test --target all --deny-warn
moon build --target all --release
moon info
moon fmt --check
```

回归文件为 `glob_regression_test.mbt` 和 `resolver_unset_test.mbt`。Studio 的独立浏览器工具、运行方式及断言范围见 [STUDIO-BROWSER-TEST.md](STUDIO-BROWSER-TEST.md)。CI 继续执行四后端源码验证和 Studio 构建；浏览器工具需要单独安装 Chrome，不把普通 JS 构建等同于浏览器交互验证。

最终补丁在 Windows 本地执行以上全部命令通过，四后端各 **178/178**，比此前各 164 项增加 14 项。生成的公开 `.mbti` 接口无差异，`git diff --check` 通过。真实 Chrome 验证了诊断行号、第 1/4/7 行跳转、目标切换、格式化和主题持久化，工具正常以退出码 0 结束并关闭自有进程。

本记录随源码提供复现入口；远程 CI 和注册表发布结果以对应提交及公开服务记录为准。此前 `0.1.1` 的验证保留在 [MAINTENANCE-20261111.md](MAINTENANCE-20261111.md)，其结果属于该历史版本。
